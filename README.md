# Smart_Meal_Planner
Welcome to the Smart Meal Planner Portal! This project aims to simplify daily meal planning by allowing users to manage recipes, check ingredient availability, and order food items easily, making the process efficient and convenient.

**Features**

Create and manage user profiles.                                                                                               
Browse and manage recipes.                                                                                                     
Check ingredient availability and add items to cart.                                                                           
Manage inventory for ingredients.                                                                                              
Place orders and make payments.                                                                                                
View order history and track orders.                                                                                           
Admin dashboard to manage recipes, ingredients, and orders.                                                                    
User-friendly interface for smooth experience.
